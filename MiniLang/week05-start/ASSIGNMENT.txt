YOUR C++ TASK — THREE CONNECTED PARTS IN src/resolver.cpp
Retain the C++ method signatures and the assignment node-dispatch condition.
Remove the TODO bodies; leave all declaration and block handlers unchanged.

1. Resolver::resolveName(const std::string &name, const SourceSpan span) const
   Visit scopes_ in reverse order, beginning at the most recent map.
   Find name in each map. If absent, continue into the next outer scope.
   At the FIRST match, inspect defined. If false, throw CompileError using
   Phase::Resolve, source_.name(), span and the message:
       cannot read variable '<name>' in its own initializer
   Substitute the actual name. Do not skip an undefined match to try outer x.
   If defined, return that binding's EXISTING id immediately. Do not allocate
   IDs, mutate maps, or return runtime values. Only after every map has no
   match, throw the same kind of error with: unknown variable '<name>'

2. Resolver::resolveExpression(Expression &expression), the complete body
   For VariableExpression, obtain mutable access to the node, call resolveName
   with its name and expression.span, store the returned ID in resolved_id,
   and return. For GroupingExpression, obtain its node, recursively resolve
   the owned child expression and return. Literals fall through unchanged.
   Do not copy an AST node and annotate only the copy. Do not evaluate values.

3. AssignmentStatement branch in Resolver::resolveStatement(Statement &statement)
   Resolve the target name using assignment->name and assignment->name_span;
   store that ID in assignment->resolved_id. Then resolveExpression on
   assignment->value, and return. The target must already be declared.
   Resolve the value even if target lookup succeeds: it may contain a grouped
   read or an unknown name. Assignment does not create a new declaration ID.

The same lookup policy serves expression reads and assignment targets.
Do not implement a second scope stack or repeat declare()/define()/block
traversal. Those parts already provide the scopes and declaration identities.
